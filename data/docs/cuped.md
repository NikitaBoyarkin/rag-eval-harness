# CUPED

CUPED (Controlled-Pre-Experiment-Data) reduces the variance of an A/B test estimate using a pre-period covariate. You compute an adjusted outcome Y_adj = Y - theta * (X - mean(X)), where theta = Cov(Y, X) / Var(X) and X is a pre-period measure correlated with Y. The ATE point estimate on Y_adj is unchanged in expectation but its variance shrinks by roughly (1 - rho^2), where rho is the correlation between the covariate and the outcome. The practical effect is a narrower confidence interval: an experiment that needed 10000 users per arm can reach the same power with about 5600. CUPED costs nothing but requires a pre-period covariate collected before assignment. It improves sensitivity, not the estimate itself; the treatment effect is the same number with a smaller error bar.
