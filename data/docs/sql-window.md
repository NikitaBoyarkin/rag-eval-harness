# SQL Window Functions

A window function computes a value over a set of rows related to the current row, without collapsing them like GROUP BY. ROW_NUMBER assigns a unique rank within a partition; RANK leaves gaps after ties; DENSE_RANK does not. A partition restarts the window per group, for example per country, and an ORDER BY inside the window defines the ranking. A running total uses SUM(amount) OVER (ORDER BY day ROWS UNBOUNDED PRECEDING). Top-N per group is ROW_NUMBER() OVER (PARTITION BY country ORDER BY revenue DESC) wrapped in a subquery that keeps rows where the rank is at most N. The gaps-and-islands pattern labels consecutive runs by subtracting a row number from the date: day minus row_number is constant within one consecutive run and jumps at a gap, turning runs into groupable keys.
